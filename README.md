# duskrawl-releases

Official release binaries of [Duskrawl](https://github.com/mhartkhiss/DuskCore-Hub)
(the Deskrawl automation suite).

This repository holds **release assets only** — no source commits are pushed
here. Each release carries a flat Windows ZIP (`Duskrawl_v<game>-revN.zip`)
that the in-app updater consumes. Tags look like `v1.0.0i-rev1`
(`<game bundle version>-rev<trainer revision>`).
